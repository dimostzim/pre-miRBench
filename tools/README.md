# Pre-miRNA Prediction Tools

Unified wrapper for benchmarking pre-miRNA prediction tools.

## Available Tools

- **mustard** - Multi-scale CNN with structure and conservation
- **mire2e** - End-to-end Transformer
- **mirdnn** - Hybrid CNN/RNN with structure
- **dnnpremir** - CNN with structure
- **deepmir** - Image-based CNN with structure
- **deepmirgene** - RNN with attention and structure

## Setup

Build a tool image from the repository root:

```bash
cd tools
./setup.sh --tool {tool}
cd ..
```

Download a tool's bundled smoke-test data if needed:

```bash
cd tools/{tool}
./download_test_data.sh
cd ../..
```

## Run Inference

Run from the repository root:

```bash
python tools/inference.py --tool {tool} --output-name my_run
```

## Retrain Models

Retraining uses Docker and writes artifacts under `results/training/{tool}/{run-name}/`:

```bash
python tools/train.py --tool {tool} --run-name my_model --config configs/train/{tool}_train.yaml
```

The default training configs point to inputs generated by
`benchmark/train_data/build_dataset.py`. That pipeline creates one canonical
200 nt positive/negative window dataset, then writes tool-specific views under
`data/train/tool_inputs/{tool}/`. FASTA-native tools use positive/negative
FASTA files; dnnPreMiR inputs are cropped to 180 nt before folding; mirDNN
inputs are cropped to its configured `seq_length`; miRe2e inputs are cropped to
100 nt; MuStARD uses 200 nt BED intervals plus genome/conservation inputs.
After a successful run, `inference_config.yaml` is written in the training
result directory and can be passed to `tools/inference.py`.

Training wrappers require a visible GPU. `tools/train.py` passes `--gpus all`
to Docker, and the in-container wrapper fails fast if TensorFlow/PyTorch cannot
see CUDA.

## Configuration

Edit `configs/{tool}_config.yaml` to set default parameters, or pass an explicit config file with `--config`.

Build the default training inputs first, for example:

```bash
python benchmark/train_data/build_dataset.py \
  --genome data/train/raw/ucsc/hg38_chr14/chr14.fa \
  --bed data/train/raw/mirgenedb/hsa-all.bed \
  --output-dir data/train \
  --ratio 5
```

Pass an explicit config file with `--config` to train on another prepared
dataset.

## Results

Results are written to `results/{tool}/{output-name}/`.
